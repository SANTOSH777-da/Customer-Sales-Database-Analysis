# Customer & Sales Database Analysis (SQL)

## Project Overview
This project demonstrates SQL-based analysis of customer purchases, product sales, and revenue trends using MySQL.

## Database
- customer_sales_db

## Tables
- Customers
- Products
- Orders

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT INTO
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- INNER JOIN
- Aggregate Functions (SUM, AVG, COUNT, MAX, MIN)

## Business Analysis
- Customer Analysis
- Product Analysis
- Monthly Sales Trend
- Revenue Analysis
- Top Revenue Customers
- Top Selling Products
- Revenue by State
- Revenue by Payment Method
